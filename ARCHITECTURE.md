## Data Flow

### 1. Monthly Update Workflow

```
MONTH 1
├─ Update Excel Files
│  ├─ Add new SOI tracking data
│  ├─ Update BP completion status
│  └─ Update executive initiatives
│
├─ Convert to JSON
│  └─ $ python convert-excel.py
│     Generates:
│     • soi-tracking.json (monthly data)
│     • soi-completed.json (BP status)
│     • executive.json (initiatives)
│
├─ Commit to GitHub
│  └─ $ git add data/
│     $ git commit -m "Update monthly data"
│     $ git push origin main
│
└─ Deploy to GitHub Pages
   (Automatic - 30 seconds)
   └─ Dashboard updates instantly
      https://username.github.io/qbr-dashboard/
```

### 2. Data Processing Pipeline

```
Excel Files (.xlsx)
        │
        ├─► openpyxl (Python library)
        │
        ├─► Clean Data
        │   ├─ Remove null values
        │   ├─ Parse dates
        │   ├─ Convert to numbers
        │   └─ Extract relevant columns
        │
        ├─► Validate
        │   ├─ Check BP codes
        │   ├─ Verify numeric fields
        │   └─ Flag errors
        │
        ├─► Transform to JSON
        │   ├─ Monthly structure
        │   ├─ Standardize fields
        │   └─ Add metadata
        │
        └─► Save JSON Files
            ├─ data/soi-tracking.json
            ├─ data/soi-completed.json
            └─ data/executive.json
```

### 3. Dashboard Rendering

```
Browser Loads index.html
        │
        ├─► Parse HTML Structure
        │
        ├─► Load CSS Styling
        │   ├─ Colors & gradients
        │   ├─ Layout (grid/flexbox)
        │   └─ Responsive design
        │
        ├─► Load JavaScript
        │   ├─ Navigation handlers
        │   ├─ Data loading functions
        │   └─ Chart.js library
        │
        ├─► Fetch JSON Data
        │   ├─ data/soi-tracking.json
        │   ├─ data/soi-completed.json
        │   └─ data/executive.json
        │
        ├─► Process Data
        │   ├─ Filter by month/quarter
        │   ├─ Calculate aggregates
        │   ├─ Compute metrics
        │   └─ Sort & group
        │
        ├─► Render Charts
        │   ├─ Line charts (trends)
        │   ├─ Bar charts (comparisons)
        │   └─ Summary tables
        │
        └─► Display Dashboard
            ├─ 5 interactive tabs
            ├─ Real-time filtering
            └─ Responsive mobile view
```

## Security & Privacy

### What's Public
- Dashboard URL is publicly accessible
- Anyone can view the data if they have the link
- No authentication required
- No sensitive credentials stored in repo

### What's Private
- Your GitHub repository (can be private if needed)
- Raw Excel files (not uploaded)
- Commit history
- Conversion process

### Best Practices
```
✅ DO:
- Keep sensitive data out of comments
- Use generic BP codes if needed
- Review public information classification
- Consider repository visibility settings

❌ DON'T:
- Upload files with passwords
- Include API keys or credentials
- Share private dashboard link
- Store Personal Identifiable Information (PII)
```

## Troubleshooting Decision Tree

```
Dashboard not loading?
├─ YES: Check GitHub Pages status
│       └─ Settings > Pages
├─ NO: Check browser console
│      └─ F12 > Console tab > Look for errors

Charts not showing?
├─ Check JSON files exist
│  └─ data/ folder should have 3 JSON files
├─ Validate JSON format
│  └─ jsonlint.com
├─ Check browser internet connection
│  └─ Chart.js CDN must load

No data showing?
├─ Check console for fetch errors
├─ Verify file names:
│  ├─ soi-tracking.json
│  ├─ soi-completed.json
│  └─ executive.json
├─ Confirm JSON structure matches

Updates not showing?
├─ Wait 2-3 minutes for build
├─ Hard refresh: Ctrl+Shift+R
├─ Check GitHub Pages build status
└─ Verify git push succeeded
```
